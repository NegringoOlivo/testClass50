# 🔄 Actividad Práctica: Dominando el Ciclo `for` en Java

## 🎯 Objetivo de la Actividad
Comprender e implementar el uso de la estructura de control repetitiva `for` en Java para procesar secuencias de datos, automatizar tareas iterativas y manejar acumuladores.

---

## 📝 Descripción del Reto: "Analizador de Datos Meteorológicos"
¡Es hora de codificar! Tu misión es desarrollar un programa en Java que simule la lectura de temperaturas de una estación meteorológica durante una semana (7 días). El programa deberá solicitar la temperatura de cada día, procesarla y arrojar estadísticas básicas.

### ⚙️ Requisitos Técnicos
Tu código fuente debe cumplir con las siguientes especificaciones:

- [ ] 📥 **Entrada de datos:** Utilizar la clase `Scanner` para solicitar datos por consola.
- [ ] 🔄 **Iteración:** Utilizar un ciclo `for` que se repita exactamente **7 veces** (una por cada día de la semana).
- [ ] ➕ **Acumuladores:** Sumar todas las temperaturas ingresadas durante las iteraciones.
- [ ] 📊 **Cálculos:** Al finalizar el ciclo, calcular y mostrar el **promedio** de temperatura de la semana.
- [ ] 🌡️ **Bonus (Opcional):** Identificar y mostrar cuál fue la temperatura más alta registrada durante esos 7 días.

---
